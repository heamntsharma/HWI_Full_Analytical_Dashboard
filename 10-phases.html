Scientific interpretation

Combining four independent observation systems — in-situ station data (IMD ↗), satellite remote sensing (MODIS ↗), global reanalysis (ERA5 ↗) and regulatory air-quality monitoring (CPCB ↗) — triangulates the heat signal from complementary vantage points: near-surface air temperature, land-surface radiative temperature, atmospheric moisture/energy state, and particulate loading. This multi-source design mitigates single-instrument bias and gap-fills spatial coverage where any one network is sparse.

Heatwave Frequency (HWF) and Heatwave Index (HWI), the eventual target variable, are derived directly from IMD's operational temperature-based heatwave criteria — anchoring the label in an established meteorological definition rather than an ad-hoc threshold.

Scientific interpretation

Quality control is inserted before any modelling step, not after — this is deliberate. A VIF < 10 threshold controls multicollinearity among strongly correlated climate variables (e.g. Tmax and LST), which would otherwise inflate coefficient variance in linear-family models and destabilise SHAP attribution downstream in Phase 7. The dataset shape is unchanged (7,956 rows × 22 variables), confirming cleaning corrected values in place rather than discarding observations.

Scientific interpretation

Feature count expands from 22 raw variables to 35 engineered features (≈1.59× enrichment) in the current dataset. Lag and rolling-window features encode memory in the climate system (heat accumulation, soil-moisture deficit persistence), which a purely contemporaneous feature set cannot capture — hover the lag / roll tags ↑ above for what each window actually represents. Interaction terms such as LST×NDVI approximate the physical modulation of surface heating by vegetation cover, giving tree-based models an explicit signal rather than forcing them to rediscover it via splits.

PHASE 04 / 10

Temporal train / test split

Chronological split to ensure robust model validation and avoid data leakage

Train — 2000–2017

  • ~5,569 rows (70%)
  • Purpose: model training

Test — 2018–2025

  • ~2,387 rows (30%)
  • Purpose: out-of-sample evaluation
Scientific interpretation

A chronological (not random) split is the single most important safeguard in this pipeline. Climate observations are strongly autocorrelated in time; a random shuffle would place future information in the training fold and produce an optimistic, non-generalisable R². Training on 2000–2017 and testing strictly on the unseen 2018–2025 window mimics genuine forecasting conditions and is the same principle later enforced inside TimeSeriesSplit cross-validation (Phase 5) and Leave-One-Region-Out validation (Phase 6).

PHASE 05 / 10

Machine learning model development & training

Objective 3 — Develop and evaluate leakage-free predictive models for Heatwave Index (HWI)

Candidates evaluated

  • Linear Regression (baseline)
  • Ridge Regression (L2)
  • Random Forest (bagging)
  • Gradient Boosting ★ primary
  • SVR (RBF kernel)
  • MLP Regressor

Validation strategy

  • TimeSeriesSplit, k = 5 folds
  • Forward-chaining, no shuffle
  • GridSearchCV hyperparameter search

Leakage-free feature set

  • HSI_lag1 removed
  • HSI_roll3 removed
  • Both derived directly from target
Prevents look-ahead bias
Scientific interpretation

Six model families spanning linear, kernel, bagging, boosting and neural architectures are benchmarked under an identical, leakage-free feature set and identical time-aware CV — isolating the comparison to model capacity rather than data handling differences. Removing HSI_lag1/HSI_roll3 is essential: since HSI (Heatwave Severity/Intensity) is closely related to the HWI target, retaining its own lag would let the model "cheat" by nowcasting rather than forecasting. Gradient Boosting was pre-registered as the expected-best candidate given its strength on structured, non-linear, interaction-rich tabular data.

Scientific interpretation

The three validation regimes probe three distinct failure modes. Temporal CV (R² = 0.911) tests whether the model holds up across different training/test year splits. Spatial LORO-CV (R² = 0.875) is the more demanding test — it withholds an entire district/region the model has never seen, and its modestly lower score is expected and healthy: it quantifies genuine geographic transferability rather than memorised local patterns. The gap between LORO-CV and the final test R² (0.982) indicates the model generalises well temporally but, appropriately, shows somewhat more uncertainty across unseen geography.

Scientific interpretation

Triangulating three independent importance methods — impurity-based gain, permutation (error-based) importance, and SHAP (game-theoretic attribution) — guards against method-specific artefacts (e.g. impurity gain's known bias toward high-cardinality features). Max_Temp_roll3 topping all three rankings confirms that short-term temperature accumulation, not any single day's reading, is the dominant physical driver of heatwave intensity, followed by land-surface temperature persistence (LST_lag1) and heatwave frequency (HWF) — consistent with heat being a cumulative, not instantaneous, hazard.

Scientific interpretation

Non-parametric methods (Theil–Sen slope, Mann–Kendall, Spearman ρ) are chosen deliberately over OLS trend fitting or Pearson correlation because climatic extremes are frequently non-normally distributed and outlier-prone — a single anomalous heatwave year should not dominate a least-squares trend line. This phase runs entirely on the same leakage-free feature set as modelling, so the descriptive trend story and the predictive model story remain consistent with one another.

9.4 Bootstrap CI

  • B = 1,000 iterations

5th–95th percentile CI
Scientific interpretation

Projections are generated by combining a statistical trend extrapolation (Theil–Sen) with the trained GBM applied to scenario-consistent CMIP6 ↗-forced features — rather than extrapolating the ML model in a vacuum, which would risk unphysical behaviour outside the training distribution. Bootstrap resampling across districts (B = 1,000) propagates spatial sampling uncertainty into a 90% confidence band, which is essential given only 306 districts feed each scenario estimate. Divergence between SSP1-2.6 (strong mitigation) and SSP5-8.5 (high emissions) by the 2080s–2100s is the expected signature of a well-behaved climate-sensitive model — the wider the fan, the more the outcome hinges on the emissions pathway actually taken.
